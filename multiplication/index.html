Параметры

Для новичка всё просто: выбрал операцию и диапазон — получил лист. Учитель может включить ответы.

Листы — живой предпросмотр; при печати каждый = ровно страница А4. Тренажёр автоматизма счёта: учителю не надо придумывать примеры вручную, родителю — не надо покупать дополнительные тетради.
